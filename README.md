# 🚀 CodeSync  
### Real-Time Collaborative IDE with AI Assistance & Distributed Session Architecture
## 🔗 Live Demo  
👉 https://code-sync-sooty.vercel.app/

> A real-time collaborative coding platform enabling multiple users to code together, execute programs, and leverage AI-powered code intelligence in shared environments.

---

## 🧠 Overview

CodeSync is a distributed real-time collaborative development system designed for pair programming, technical interviews, and live coding collaboration with AI-assisted analysis.

---

## ⚙️ Architecture

Frontend (React + Monaco Editor)  
→ Socket.io Real-Time Layer  
→ Node.js Backend (Express)  
→ AI Engine (Gemini API) + Execution Engine  
→ Firebase Firestore (Events + Snapshots)

---
